================================================================================
                        GAME FLOW SUMMARY
================================================================================

HOST SIDE:
  1. Create Room → Get 4-letter code
  2. Wait for players to join
  3. Select game (Tanks War)
  4. Click Start Game
  5. Watch canvas with live gameplay
  6. Game ends when winner determined
  7. Can start another game (same players)

PLAYER SIDE:
  1. Enter room code + name
  2. Join room
  3. Wait for host to start game
  4. When game starts: see controller
  5. Use buttons/keyboard to control tank
  6. Eliminate opponents by shooting
  7. Last tank alive wins!
  8. Return to waiting for next game

FIREBASE BACKEND:
  - Real-time sync for all state
  - Room info (phase, game, players)
  - Player positions, HP, bullets
  - Input throttling (20 updates/sec max)
  - Game state persistence

================================================================================
                     EXTENDING THE PROJECT
================================================================================

To add a new game:

1. Add to gameRegistry.js:
   const GAMES = {
     myGame: { id: 'myGame', name: 'My Game', ... }
   };

2. Create game logic (src/games/myGameLogic.js):
   - export createInitialState()
   - export updateState()
   - export detectWinner()

3. Create host game (src/host/myHostGame.js):
   - export startMyGameLoop()

4. Update hostController.js and playerController.js

5. Add UI for players in playerView.js

See DEVELOPMENT.md for detailed instructions.
